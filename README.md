# 🏨 OurPalace Hotel Website

A modern, responsive hotel website built using HTML and CSS.  
This project showcases a complete multi-page hotel booking UI with clean design, structured layout, and professional styling.

---

## 🚀 Features

- ✨ Responsive design (mobile, tablet, desktop)
- 🏨 Room listing with pricing and features
- 🖼️ Image gallery with uniform grid layout
- 🛎️ Services and amenities section
- 📖 About page with hotel story and mission
- 📞 Contact form and location section
- 🎯 Clean UI with modern card-based design
- 🎨 Consistent color theme and typography

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Flexbox & Grid)
